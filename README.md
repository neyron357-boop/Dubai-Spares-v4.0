# Stark Motors · Local Workspace

Локальное приложение для подбора автозапчастей: заказы, поставщики, фотографии, предложения, сметы и счета.

Открыть: https://neyron357-boop.github.io/Dubai-Spares-v4.0/

## Работа с данными

Сервер, Supabase, облачная авторизация и AI API удалены. Все рабочие данные сохраняются в браузере. Заказы и документы используют IndexedDB; контакты, настройки, библиотека предложений и история — локальное хранилище. Существующая база `dubai-spares-offline` и ключи хранения сохранены, чтобы обновление не стирало данные.

После первого открытия приложение кеширует все экраны, шрифты и ресурсы. Его можно установить на главный экран и использовать без интернета. Для карт, WhatsApp, Telegram и внешних фотографий интернет нужен только при обращении к этим внешним ресурсам.

**Настройки → Система → Экспорт локального бэкапа** сохраняет заказы, фотографии, поставщиков, варианты цен, настройки, историю и сметы в JSON. Там же доступно восстановление с проверкой файла и подтверждением замены заказов. Делайте резервные копии: очистка данных браузера удаляет локальную базу. Данные разных браузеров и устройств не синхронизируются автоматически.

Форма заявки сохраняет заявку на текущем устройстве и позволяет скачать файл для передачи менеджеру. Смета передаётся через ссылку со встроенным снимком данных; крупная смета с медиа сохраняется в файл. Получатель может открыть такой файл через **Настройки → Система → Смета из файла**. Отправленная смета — снимок на момент отправки: новые изменения нужно передавать повторно.

## Локальный запуск

Требуется Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Настройка переменных окружения и ключей API не требуется.

```sh
npm run check          # TypeScript, ESLint, unit tests, production build
npm run test:e2e       # Browser workflows
npm run test:e2e:offline # Production offline workflows; run build first
npm run preview       # Open the production build locally
```

GitHub Actions проверяет проект и публикует статическую сборку в GitHub Pages. Хостинг раздаёт файлы приложения; серверной базы данных и backend нет.

## Интерфейс и архитектура

Общие цвета, размеры, фокус и анимации заданы в `tailwind.css`. Компоненты кнопок, полей, панелей и диалогов находятся в `components/ui.tsx`. На компьютере используется боковая панель, на телефоне — подписанная нижняя навигация. Отклик касаний задан в `utils/touchFeedback.ts`: элемент проседает пропорционально размеру, возвращается пружиной, прокрутка нажатие отменяет; на Android переключения и результаты сопровождаются вибрацией (отключается в настройках звука). Поддерживаются клавиатура, системное уменьшение анимаций и безопасные зоны экрана.

- `orderStore.ts` — локальные заказы и последовательное сохранение после завершения транзакции.
- `orderNormalization.ts` — совместимость старых данных.
- `storage/offlineDb.ts` — существующая база, безопасное восстановление и резервные копии.
- `storage/localDocuments.ts` — сметы и локальные сессии поиска.
- `storage/photos.ts` — сжатие фотографий и локальные вложения.
- `utils/localBackup.ts` — экспорт, валидация и восстановление с откатом при ошибке.
- `publicQuoteApi.ts` — формирование и чтение локальных смет.
- `utils/quotePricing.ts` — единый расчёт стоимости, скидки, депозита и остатка.

История удалённого серверного кода доступна в git. Обновление не удаляет внешние проекты или данные в бывших облачных сервисах.
