# Аудит приложения · 2026-10-06

## Что проверено

- TypeScript, ESLint, Prettier, production-сборка.
- 101 unit-тест, 86 браузерных сценариев, 2 офлайн-сценария на production-сборке.
- Все экраны на iPhone 13 (390×844): ошибки консоли, горизонтальная прокрутка, скриншоты.
- Зависимости (`npm audit`), PWA-манифест, service worker, расчёт денег, резервные копии.

## Найдено и исправлено

| Проблема                                                               | Последствие                                                      | Исправление                                                                                                                    |
| ---------------------------------------------------------------------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Уязвимость `source-map-js` (high) в инструментах сборки                | CI падал на `npm audit`, следующая публикация не прошла бы       | Обновлена зависимость; CI строго проверяет код для пользователей, инструменты сборки — с уровня high                           |
| Вставка суммы `1,000,000` или `1.250.000` давала `1.00` / `1.25` AED   | Неверная цена в предложении                                      | Повторяющийся разделитель с группами по 3 цифры считается разделителем тысяч; случайная лишняя точка при вводе не меняет число |
| Ссылка на файл удалялась сразу (или через 1 с) после начала скачивания | На iPhone/Firefox бэкап, смета или картинка могли не сохраниться | Общий `utils/downloadFile.ts`, ссылка живёт 60 с                                                                               |
| `theme-color` тёмно-синий при светлом интерфейсе                       | Тёмная полоса браузера над белой шапкой на Android               | Цвет темы совпадает с фоном приложения                                                                                         |

## Без изменений

Архитектура, хранение данных (IndexedDB + localStorage), офлайн-режим и интерфейс в хорошем состоянии: ошибок консоли нет, вёрстка не выходит за экран от 320 px. Полная переписка с нуля не нужна и создала бы риск потери данных пользователей, поэтому исправлены конкретные дефекты.
